# 学习技能树 Skill Tree

![学习技能树演示插画](assets/doubao-1.jpg)

一个可扩展的学习与游戏化复习平台：把课程内容组织成「章节 → 技能卡片」，通过碎片式答题、经验值、复习抽检和刷卡学习形成完整学习闭环。

> 演示插画为 AI 生成的装饰素材，仅用于页面展示。

> 本仓库为演示版：已移除个人开发日志与私人内容，仅保留可展示的功能与示例内容。

## 在线演示

https://sien-1.github.io/public-demo/

## 功能

- **多内容包架构**：每门学科一个独立数据文件，进度互不干扰
- **概念卡片**：支持分区块讲解（定义 / 辨析 / 关联）
- **碎片式答题**：数字框 + 小键盘 + 符号选择芯片，纯选择题自动隐藏小键盘
- **自动判题**：数值容差、科学计数法、选项随机排列
- **复习抽检**：每完成 3 个技能触发旧技能抽检；最近复习队列避免短时间重复
- **进阶挑战**：可选附加题，奖励附加经验，不占主线进度、不进入抽检
- **刷卡学习**：按章节顺序刷完整章，或只复习本包已掌握技能
- **示意图**：支持手绘图片导入，点击可放大
- **相关度搜索**：按名称相关 / 内容提及分组并高亮命中原文
- **番茄钟工具**：25 分钟专注 + 5 分钟休息、连续模式、自定义奖励目标、今日任务

## 技术栈

- 原生 HTML + CSS + JavaScript，无框架、无后端
- 进度与设置保存在浏览器 localStorage
- 内容与程序分离：新增学科只需新增 JSON 并登记索引

## 本地运行

1. 用 VS Code 打开本文件夹
2. 安装 Live Server 扩展
3. 右键 `index.html` → **Open with Live Server**

## 内容数据格式

每个技能卡包含：

- `name`：技能名称
- `exp`：经验值
- `concept`：概念讲解（可选 `sections` 分区块）
- `question` / `answer` / `answerSchema`：练习题与判题结构
- `reviewQuestion` / `reviewAnswer` / `reviewAnswerSchema`：复习题
- 可选 `conceptFigure` / `questionFigure`：示意图路径

章节可附加可选 `challenges`（进阶挑战）。

## 开发方式

项目由个人设计与维护，开发流程为：

1. 从真实学习需求出发设计功能与交互
2. 使用 AI 辅助生成实现方案与代码
3. 人工逐项验收、测试并迭代修正
4. 用 Git 管理版本，记录每一步演进
